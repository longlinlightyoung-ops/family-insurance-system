# 家庭保单管理系统

一个用于管理家庭保单的Web应用程序，支持家庭成员管理、保单添加、缴费提醒、保费总览等功能，适配手机端和电脑端使用。

## 功能特点

1. **家庭成员管理**
   - 添加/编辑家庭成员信息
   - 记录成员与本人关系、联系方式等
   - 查看每个成员的保单数量

2. **保单管理**
   - 手动添加保单详细信息
   - 编辑和删除现有保单
   - 按状态、类型等筛选保单
   - 查看保单完整信息

3. **提醒功能**
   - 缴费日自动提醒（支持自定义提前天数）
   - 到期日自动提醒
   - 应用内通知提醒

4. **保费总览**
   - 年度/月度保费统计
   - 按成员分布的保费图表
   - 按保险类型分布的保费图表
   - 保费趋势分析

5. **数据管理**
   - 本地存储（使用浏览器localStorage）
   - 数据导入/导出功能
   - 数据备份提醒

## 技术特点

- 响应式设计，适配手机端和电脑端
- 使用Chart.js生成数据可视化图表
- 纯前端实现，无需后端服务器
- 使用LocalStorage进行数据持久化
- 现代化的UI设计，用户友好

## 使用说明

### 初始设置
1. 打开应用后，首先在"家庭成员"页面添加所有家庭成员
2. 然后在"所有保单"页面添加已有的保单
3. 设置提醒偏好（在"设置"页面）

### 日常使用
- 仪表板：查看概览信息和重要提醒
- 家庭成员：管理家庭成员信息
- 所有保单：查看和管理所有保单
- 保费总览：查看保费统计和图表
- 提醒：查看即将缴费和到期的保单
- 设置：配置应用偏好和数据管理

### 数据备份
由于数据存储在本地浏览器中，建议定期使用"导出数据"功能备份数据，以防数据丢失。
